# Development Guidelines

To maintain a consistent, high-quality codebase throughout this repository, please follow these principles:

1. **Write clean, flexible code** that is easy to understand, modify, and extend.
2. **Adhere to SOLID principles**, ensuring components are well-structured, modular, and resilient to change.
3. **Apply the DRY (Don't Repeat Yourself) philosophy** to eliminate unnecessary duplication and encourage reuse.
4. **Keep implementations simple (KISS)** by avoiding over-engineering and focusing on straightforward, maintainable solutions.

These guidelines apply to every file within this repository unless a more specific `AGENTS.md` file provides additional instructions.
